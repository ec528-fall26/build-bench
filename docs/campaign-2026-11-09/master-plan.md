## 1. Thesis (five lines)
1. Hosted runs give no build feedback and one validation, so the score is the quality of one edit set plus not corrupting it. Both gains and losses come from facts the agent lacks, and from free-form edits it types badly.
2. Phase-two experiments turned 4 of 5 "unknown/unrepairable" cases into VERIFIED recipes (libevtx, libmceliece, html-xml-utils, pybigwig; ectrans and libbpp-qt variants also passed). The agent's gap is delivering such recipes, not discovering them.
3. So: a registry of recogniser + probe + deterministic expander ("recipes"), each with a tier (verified / historical / hypothesis), so the model picks an id and the controller writes the edit.
4. Underneath: make the facts readable (zstandard for 3,305 of 3,394 deps), gate edits with grammar/consequence checks that only BLOCK on mechanical facts, and make the loop commit to an edit and never lose it.
5. Everything is behind flags, main's tests stay green with flags off, and anything not green by Thu 12 Nov 12:00 UTC ships off. Static layers should be expected near Meta's +5.6 points, not beyond.

## 6. What we tell the professor
Ingenious parts, honestly scoped:
- Evidence-grounded recipes: the model chooses WHETHER a repair applies, the controller decides HOW; each recipe carries a tier (verified/historical/hypothesis) and refuses rather than guesses. This idea worked once (libbpp-core: a 4,130-line retype became a 13-line edit in one attempt) and we generalise it.
- Phase-two experiments with the real validator (not the model) corrected our own earlier conclusions: libmceliece (-Wl,-Bsymbolic-functions strip passes), pybigwig (in-package fix passes), html-xml-utils (serial cexport build keeps LTO/hardening, the old accepted repair did not), libevtx (one-line __OPTIMIZE__ guard, FAIL 0). We show what we got wrong, as science.
- Making hidden facts readable: 3,305 of 3,394 dependency packages could not be opened; one pinned wheel fixes it, verified in the exact hosted image.
- Edit-quality gates catching "passes for the wrong reason" (accepted by dpkg because it dropped our lines; tests turned off).
Limits we state: 11 dev cases are in-sample; no build feedback exists hosted, and the literature says execution is the dominant lift, so a static layer should land near +5.6 points; our hidden-set class shares are estimates (+/-8); recipes are single-case-verified (tier shown); hosted model unknown. No claim of a gain number before the Thursday A/B and held-out report.
